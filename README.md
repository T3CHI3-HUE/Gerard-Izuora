# Videographer Portfolio

Static portfolio site (HTML/CSS/JS). Open `index.html` in a browser.

## How to customize
- Replace video assets in `./assets/`:
  - `featured.mp4` and `featured-poster.jpg`
  - `brand-launch.mp4` + `brand-launch-thumb.jpg`
  - `event-highlights.mp4` + `event-highlights-thumb.jpg`
  - `creator-promo.mp4` + `creator-promo-thumb.jpg`
- Edit projects in `script.js` (array `work`).
- Update email/phone/social links in `index.html`.

## Run
- No build step. Use: `open index.html` (macOS).
